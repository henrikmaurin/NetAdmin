NetAdmin.Core
=============

Shared core library for the NetAdmin solution. Contains domain models, common utilities, base classes, and interfaces used across provider projects and the Web UI.

Key points:
- Intended to be reused by provider projects (NetAdmin.Providers.*) and UI modules.
- Follow C# 14 / .NET 10 conventions described in .opencode/skills/code-style-and-reuse/SKILL.md

Build
- This is a standard .NET class library; build with `dotnet build`.
