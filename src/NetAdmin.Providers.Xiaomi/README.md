NetAdmin.Providers.Xiaomi
=========================

Provider integration for Xiaomi devices. Implements the NetAdmin provider interface to discover, monitor, and control Xiaomi hardware supported by the project.

Key points:
- Conforms to the Provider Architecture guidelines in .opencode/skills/provider-architecture/SKILL.md
- Keep provider-specific logic inside this project; reuse common code from NetAdmin.Core.

Build
- Build with `dotnet build`.
